# Remote Mouse — Windows

Сервер для Windows. Принимает одно подключение с телефона в локальной сети и выполняет команды: курсор, клики, прокрутка, текст в активном поле, сочетания клавиш, громкость и управление воспроизведением.

Приложение живёт в трее. Одновременно обслуживается один телефон.

## Что умеет

- Показывает QR-код и 6-значный код для первого подключения.
- Запоминает телефон. В следующий раз код не нужен.
- Движение курсора, уровень громкости и позиция воспроизведения приходят по UDP, остальные команды — по WebSocket.
- Читает название и состояние текущего медиа и подставляет текст в поле, которое сейчас в фокусе.
- Может запускаться вместе с Windows.

## Как пользоваться

1. Запустите `RemoteMouse`. В трее появится иконка.
2. Щёлкните по ней левой кнопкой. В окне откройте подключение и оставьте на экране QR или код.
3. Подключитесь с телефона (приложение [RemoteMouse](https://github.com/H1lp0p/RemoteMouse-android)). Пока сессия открыта, второй телефон получит отказ.
4. Правый щелчок по иконке: Open, Start with Windows, Exit.

Порты 12345 и 12346 должны быть доступны в локальной сети. Если 12345 занят, закройте второй экземпляр программы.

Сохранённые устройства лежат в `%AppData%\RemoteMouse\state.json`.

## Сборка

Нужен .NET 8 SDK.

Из корня проекта:

```powershell
dotnet build src\RemoteMouse.App\RemoteMouse.App.csproj -c Release
dotnet run --project src\RemoteMouse.App\RemoteMouse.App.csproj -c Release
```

Собранный файл: `src\RemoteMouse.App\bin\Release\net8.0-windows10.0.19041.0\RemoteMouse.exe`. На компьютере, где его запускают, должен стоять runtime .NET 8 для Windows.
